# docs/superpowers —— 项目设计目录

本目录只放**项目设计**：需求原话、专题设计、契约、不变量、验收判据、计划、调查与评审。
项目维护流程在 `../agents/`；根路由在 `../../AGENTS.md`。

## 子目录

| 路径 | 放什么 |
|---|---|
| `specs/` | 专题设计稿：需求原话、目标运行序列、契约、不变量、验收判据 |
| `plans/` | 按设计拆出的实施顺序；不是设计本身 |
| `reports/` | 调查、审计、复现与证据摘要（**只作追溯，不作当前事实**） |
| `reviews/` | 独立评审与裁决 |
| `status/` | dated 历史快照；不是当前状态入口 |
| `DESIGN_RULINGS.md` | D-xxx 索引：用户设计裁定逐字原话 + 落点 |

## 局部规则

- 设计稿必须有「不变量」与「验收判据」两节，否则不算设计完成。
- 报告里的事实要给 `file:line` 或命令 + 输出；推断必须标「推断」。
- 被取代的设计不删除，加状态头与取代者；索引在 `DESIGN_RULINGS.md`。
- 用户当次裁定优于任何旧不变量文档（见 `../AGENTS.md` §3.1）。
- 本目录中的继承来源内容必须标来源与日期，不能冒充本项目已验证事实。
