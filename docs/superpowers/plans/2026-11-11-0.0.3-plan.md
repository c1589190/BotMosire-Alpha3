## 批次 2 —— 媒体查看 / 下载（D-019，未做）

## 批次 3 —— Inbox 工具面（D-020 后半，未做）

- `inbox_items`（紧凑列表，含 id/source/priority/status/总数）；
- `inbox_get(itemId)`（该 item 的 ≤N 条 entries + total/omitted/status/revision）；
- 批量 ack：面板 1-based 序号 / 序号范围 / itemId 列表，带 revision 校验；
- `inbox_wait(timeoutMs, minPriority)`：阻塞等下一次 flush，只读不 ack，超时返回 `changed:false`；
- HTTP：`GET /items/{id}`、`GET /panel?waitSeconds=`；
- 验收：「7 个 item 时能列出全部 id」「无新条目时 wait 超时且 ack 游标不动」。

## 批次 4 —— 错误可诊断性（未做）

- OneBot：握手状态码映射（426/401/403/404/连不上/DNS）+ `qq_account_list.lastError{hint}`；
- MCP：401 区分缺 header / token 不符，响应体带 `errorCode`+`hint`（含 `BMA3_MCP_TOKEN`），日志升 ERROR；
- `qq_policy`（或 `get_config` 覆盖）：发送上限、图片上限、N/M、阈值与权重一并可读；
- 验收：`ws://` 打纯 HTTP 端口 → `hint` 直说"要 WS"；错 token → 响应体可读。
